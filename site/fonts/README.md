# Bundled fonts

`nunito-sans-{regular,600,700}.woff2` — **Nunito Sans**, Copyright 2016
The Nunito Sans Project Authors (<https://github.com/Fonthausen/NunitoSans>),
licensed under the SIL Open Font License 1.1. The full licence text is in
[`OFL.txt`](OFL.txt).

They are used only by the GitHub Pages site in `site/`. They are self-hosted on
purpose: a cross-origin font would hide its transfer size from the live badge on
that page, which would then have to withhold its grade. The OFL is a separate
licence from the project's MIT licence; it covers these font files only.
