The carbon cost of a page load, with the math shown

A web component for your footer. It reads what the page actually transferred in the visitor's browser, turns bytes into grams of CO₂e with the Sustainable Web Design Model v4, and shows N/D instead of guessing when the data is incomplete.

SWD Model v4

From bytes to grams, in the open

The estimate multiplies the bytes the browser reported by a fixed energy intensity per gigabyte and a global grid factor. The only input that changes is bytes. Drag the slider to see what that means for a page.

0.300 kWh/GB × 494 g/kWh = 148.2 g CO₂e per GB, or about 0.148 g per MB. Factors are pinned in model-factors.json and checked against the reference CO2.js implementation in the test suite. In estimate mode there is no green-hosting discount.

Get started

Paste it once, see it on the next load

No account, API key or URL setup. The script is pinned to an exact version with a Subresource Integrity hash, so the browser refuses a modified file.

STEP 1

Paste the snippet

Put it where the badge should appear, usually the footer.

<script type="module" src="https://cdn.jsdelivr.net/npm/ @cometweb/carbon-badge@2.0.6/dist/ cometweb-carbon-badge.esm.js" integrity="sha384-N55q73xI0VL1Hp6MQp5W SFoVwZUDUdfN5JsQvjhkzU9VLHguRtdTculN BP7uvm8l" crossorigin="anonymous"></script> <cometweb-carbon-badge theme="light" mode="estimate"> </cometweb-carbon-badge>
STEP 2

Match your footer

Use the dark theme on dark backgrounds and pick a smaller variant if you need one.

<cometweb-carbon-badge variant="compact" theme="dark" lang="pl"> </cometweb-carbon-badge>
STEP 3 · OPTIONAL

Or bundle it

The embed entry registers the element and loads network code only when needed.

$ npm i @cometweb/carbon-badge // in your app entry import '@cometweb/carbon-badge/embed';

The hash above matches the 2.0.6 file on jsDelivr and on cometweb.io, checked on 7 Nov 2026. WordPress, Shopify, Webflow and Wix steps and self-hosting are in the README.

What it won't claim

Honest about its limits

A footprint number is only useful if you know what it leaves out. These limits are part of the contract, not fine print.

01

An estimate, not a meter

No energy is measured. Bytes go through fixed averages, so two pages of the same weight always get the same grams.

02

One first load, not a visit

It covers what loaded before the page went quiet. Later lazy loads, return visits and whole sessions are outside the number.

03

A global grid average

494 g/kWh is a modelled global proxy with no dataset year. There is no regional grid and no confidence range.

04

Not a certificate

It is not an ESG report or a Digital Carbon Rating, and browser byte counts include a small fixed header allowance.
