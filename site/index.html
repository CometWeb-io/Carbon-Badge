Get started

Paste it once, see it on the next load

No account or API key. The script is pinned to one exact version, so the browser refuses a file that was changed.

STEP 1

Paste the snippet

Put it where the badge should appear, usually the footer.

<script type="module" src="https://cdn.jsdelivr.net/npm/ @cometweb/carbon-badge@2.0.7/dist/ cometweb-carbon-badge.esm.js" integrity="sha384-5bPSZPDLIucHdDGUKNmj LyfW/G6WfaEuJwSQ3Pn2NpMCb0oyonTqY4YN 1wfqNiBN" crossorigin="anonymous"></script> <cometweb-carbon-badge theme="light" mode="estimate"> </cometweb-carbon-badge>
STEP 2

Match your footer

Use the dark theme on dark backgrounds and pick a smaller variant if you need one.

<cometweb-carbon-badge variant="compact" theme="dark" lang="pl"> </cometweb-carbon-badge>
STEP 3 · OPTIONAL

Or bundle it

The embed entry registers the element and loads network code only when needed.

$ npm i @cometweb/carbon-badge // in your app entry import '@cometweb/carbon-badge/embed';

The hash above matches the 2.0.7 file on jsDelivr and on cometweb.io, checked on 11 Nov 2026. WordPress, Shopify, Webflow and Wix steps and self-hosting are in the README.

What it won't claim

Honest about its limits

A footprint number is only useful if you know what it leaves out. These limits are part of the contract, not fine print.

01

An estimate, not a meter

No energy is measured. Bytes go through fixed averages, so two pages of the same weight always get the same grams.

02

One first load, not a visit

It covers what loaded before the page went quiet. Later lazy loads, return visits and whole sessions are outside the number.

03

A global grid average

494 g/kWh is a modelled global proxy with no dataset year. There is no regional grid and no confidence range.

04

Not a certificate

It is not an ESG report or a Digital Carbon Rating, and browser byte counts include a small fixed header allowance.
